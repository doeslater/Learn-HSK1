# HSK 1 Course Notes

Personal study notes for the Peking University "Chinese for HSK 1" course on Coursera:
https://www.coursera.org/learn/hsk-1

## Setup

1. Clone or copy this folder locally.
2. Open `COURSE_NOTES.md` — it's the index and links to each lesson file.
3. Reference materials (PDFs, docx) live in `resources/`.

No build tools or dependencies are required — everything is plain Markdown, viewable in any text editor or Markdown previewer (e.g. VS Code, GitHub).

## Structure

```
.
├── COURSE_NOTES.md              # index — links to all lesson files
├── HSK1_Module1_Lesson1.md       # Lesson 1: 你好 Nǐ hǎo! Hello!
├── HSK1_Module1_Lesson2.md       # Lesson 2: 你是哪国人 Where are you from?
├── HSK1_Module1_Lesson3.md       # Lesson 3: 你多大了 How old are you?
└── resources/                    # PDFs, docx, and other reference material
```

## Conventions

- Lesson files are named `HSK1_Module<N>_Lesson<N>.md`.
- Each lesson file includes: 生词 (new words) table, 课文 (dialogue), sentence patterns, and exercises.

## Adding a new lesson

1. Create a new file following the naming convention above.
2. Add the course header (title, course, module, Coursera link) at the top.
3. Add a link to it from `COURSE_NOTES.md`.
